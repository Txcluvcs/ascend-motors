# Ascend Motors — инструкция

## Структура проекта

```
index.html      — главная страница
catalog.html    — каталог всех автомобилей
car.html        — страница одной машины (галерея + описание), открывается по ссылке вида car.html?id=...
styles.css      — общий дизайн для всех страниц (меняешь один раз — меняется везде)
cars.js         — список автомобилей (фото, цена, пробег, комплектация, описание) — редактируешь ТОЛЬКО этот файл
cases.js        — блок «Наши кейсы» на главной (фото + марка/модель/год, без цены) — редактируешь ТОЛЬКО этот файл
images/         — папка с фото (для машин и для кейсов)
api/send-lead.js— принимает заявки с формы и шлёт их в Telegram
```

---

## Шаг 1. Залить сайт на хостинг (Vercel)

1. Зайди на **vercel.com** → «Sign Up» → войди через GitHub (проще всего завести GitHub-аккаунт, если его нет, на github.com).
2. У себя на GitHub создай новый репозиторий, например `ascend-motors`.
3. Загрузи туда **все файлы из этой папки** (index.html, catalog.html, car.html, styles.css, cars.js, cases.js, api/, images/) — на GitHub это можно сделать прямо в браузере: «Add file» → «Upload files», перетащить всё и нажать «Commit».
4. Возвращаешься в Vercel → «Add New Project» → выбираешь свой репозиторий `ascend-motors` → «Deploy».
5. Через минуту Vercel даст ссылку вида `ascend-motors.vercel.app` — сайт уже открыт всем.

## Шаг 2. Подключить свой домен

1. Купи домен (например, ascendmotors.ru) на reg.ru или любом другом регистраторе.
2. В Vercel: Project → Settings → Domains → впиши свой домен.
3. Vercel покажет 1–2 DNS-записи (A и/или CNAME) — их нужно вставить в панели управления доменом у регистратора, в разделе «DNS-записи».
4. Домен привяжется в течение 10 минут – нескольких часов.

## Шаг 3. Как добавлять и менять автомобили

Не трогай `index.html`, `catalog.html` или `car.html` — весь список машин собирается автоматически из файла **cars.js**, сразу для всех трёх страниц (тизер на главной, полный каталог, и отдельная страница каждой машины).

Каждая машина — это блок `{ ... }` со следующими полями:

- **id** — короткий код латиницей без пробелов, например `"g63-2026"`. По нему строится ссылка на страницу машины (`car.html?id=g63-2026`). Не меняй `id` у уже опубликованной машины — иначе старая ссылка перестанет работать.
- **photos** — список фото (можно от 1 до 5): `["images/foto1.jpg", "images/foto2.jpg"]`. Первое фото — обложка карточки, остальные — галерея на странице машины.
- **make, model, year, mileage** — марка, модель, год, пробег.
- **trim** — комплектация, короткая строка.
- **description** — более подробное описание для страницы машины (необязательно, можно оставить `""`).
- **priceNoVat** / **priceVat** — цена без НДС и/или с НДС. Заполняй то, что актуально: можно одно поле, можно оба сразу — тогда покажутся обе строки цены.

Чтобы **изменить машину** — открой `cars.js`, найди её блок, поменяй нужные поля.

Чтобы **заменить или добавить фото** — положи файл в папку `images/`, впиши его имя в список `photos`.

Чтобы **добавить новую машину** — скопируй один блок `{ ... }`, вставь после последнего (не забудь запятую перед ним), поменяй данные.

Чтобы **убрать машину** — удали её блок `{ ... }` целиком. Если по старой ссылке на неё кто-то перейдёт — сайт вежливо покажет «Автомобиль не найден» со ссылкой на каталог, а не ошибку.

На главной странице тизером показываются первые 3 машины из списка — остальные видны только в каталоге (`catalog.html`).

После любого изменения — снова загрузи (замени) файл `cars.js` на GitHub (Upload files → Commit). Vercel сам обновит сайт за ~30 секунд.

## Шаг 3.1. Как добавлять кейсы

Блок «Наши кейсы» на главной собирается из файла **cases.js** — это отдельная витрина от «Автомобилей»: без цены, без «в наличии», просто фото + марка + модель + год + короткая подпись.

1. Положи фото в папку `images/`.
2. В `cases.js` скопируй один блок `{ ... }`, вставь после последнего, поменяй данные (`photo`, `make`, `model`, `year`, `note`).

## Шаг 4. Подключить форму заявок к Telegram

Чтобы заявки с сайта приходили тебе в Telegram:

1. **Создай бота.** В Telegram найди `@BotFather`, напиши `/newbot`, придумай имя. BotFather пришлёт **токен** — длинную строку вида `123456:ABC-DEF...`. Сохрани её.
2. **Узнай свой chat id.** Найди в Telegram `@userinfobot`, напиши ему `/start` — он покажет твой **Id** (набор цифр). Сохрани его.
3. **Напиши что-нибудь своему новому боту** (просто «привет») — иначе он не сможет писать тебе первым.
4. В Vercel: открой свой проект → Settings → Environments → открой окружение **Production** → добавь переменные:
   - `TELEGRAM_BOT_TOKEN` — значение из шага 1
   - `TELEGRAM_CHAT_ID` — значение из шага 2
5. Нажми Save, затем зайди во вкладку Deployments и сделай Create Deployment (или просто загрузи любой файл заново на GitHub — Vercel передеплоит автоматом).

Готово — теперь при отправке формы на сайте тебе будет приходить сообщение в Telegram с запросом клиента.

## Шаг 5. Политика конфиденциальности — пока не готова, надо доделать позже

По закону РФ (152-ФЗ «О персональных данных») сайт, который собирает имя и телефон через форму, обязан спрашивать явное согласие и иметь отдельную страницу с политикой обработки персональных данных.

Чекбокс согласия под формой уже стоит («Я даю согласие на обработку персональных данных») — без галочки форма не отправится. А вот страница с самой политикой (`privacy.html`) сейчас временно убрана — её сделаем отдельно чуть позже, и ссылку на неё нужно будет вернуть в футер и в текст чекбокса.

**Не запускай сайт на реальных клиентов, пока эта страница не появится** — без неё требование закона выполнено не полностью.

**Ещё один момент, который стоит уточнить у бухгалтера/юриста отдельно:** по закону может потребоваться подать в Роскомнадзор уведомление о начале обработки персональных данных — это отдельная процедура, не имеющая отношения к самому сайту, и требования могут зависеть от твоего статуса (ИП, самозанятый и т.д.). Я не юрист, поэтому дать точный ответ, нужно ли это в твоём случае, не могу — лучше свериться со специалистом, это разовая и не очень сложная процедура.

## Что уже работает "из коробки"

- Кнопки в шапке и хиро — переход по разделам и страницам сайта
- Клик по карточке машины (на главной или в каталоге) — открывает её отдельную страницу с галереей фото и описанием
- Кнопка «Получить предложение» на странице машины — переходит в форму на главной и подставляет туда название машины
- Кнопка «Получить варианты» в форме — реально отправляет данные (после настройки Шага 4), только если стоит галочка согласия
- Ссылка Telegram в футере уже ведёт на **@assscend** — если сменишь юзернейм, поправь в каждом HTML-файле: `href="https://t.me/assscend"`
