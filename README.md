# Ascend Motors — инструкция

## Структура проекта

```
index.html      — сам сайт
cars.js         — список машин (фото, год, пробег, цена) — редактируешь ТОЛЬКО этот файл
images/         — папка с фото машин
api/send-lead.js— принимает заявки с формы и шлёт их в Telegram
```

---

## Шаг 1. Залить сайт на хостинг (Vercel)

1. Зайди на **vercel.com** → «Sign Up» → войди через GitHub (проще всего завести GitHub-аккаунт, если его нет, на github.com).
2. У себя на GitHub создай новый репозиторий, например `ascend-motors`.
3. Загрузи туда все файлы из этой папки (index.html, cars.js, api/, images/) — на GitHub это можно сделать прямо в браузере: «Add file» → «Upload files», перетащить всё и нажать «Commit».
4. Возвращаешься в Vercel → «Add New Project» → выбираешь свой репозиторий `ascend-motors` → «Deploy».
5. Через минуту Vercel даст ссылку вида `ascend-motors.vercel.app` — сайт уже открыт всем.

## Шаг 2. Подключить свой домен

1. Купи домен (например, ascendmotors.ru) на reg.ru или любом другом регистраторе.
2. В Vercel: Project → Settings → Domains → впиши свой домен.
3. Vercel покажет 1–2 DNS-записи (A и/или CNAME) — их нужно вставить в панели управления доменом у регистратора, в разделе «DNS-записи».
4. Домен привяжется в течение 10 минут – нескольких часов.

---

## Шаг 3. Как менять фото и цены машин

Не трогай `index.html` — весь список машин собирается автоматически из файла **cars.js**.

Чтобы **изменить цену или пробег** — открой `cars.js`, найди нужную машину и поменяй число.

Чтобы **заменить фото**:
1. Положи новое фото в папку `images/` (любое имя, например `g63-new.jpg`).
2. В `cars.js` в поле `photo:` укажи это имя файла.

Чтобы **добавить новую машину** — скопируй один блок `{ ... }` в cars.js, вставь после последнего, поменяй данные.

Чтобы **убрать машину** — удали её блок `{ ... }` целиком.

После любого изменения — снова загрузи (замени) файлы на GitHub так же, как в Шаге 1 (Upload files → Commit). Vercel сам обновит сайт за ~30 секунд, никаких дополнительных действий не нужно.

## Шаг 4. Подключить форму заявок к Telegram

Чтобы заявки с сайта приходили тебе в Telegram:

1. **Создай бота.** В Telegram найди `@BotFather`, напиши `/newbot`, придумай имя. BotFather пришлёт **токен** — длинную строку вида `123456:ABC-DEF...`. Сохрани её.
2. **Узнай свой chat id.** Найди в Telegram `@userinfobot`, напиши ему `/start` — он покажет твой **Id** (набор цифр). Сохрани его.
3. **Напиши что-нибудь своему новому боту** (просто «привет») — иначе он не сможет писать тебе первым.
4. В Vercel: открой свой проект → Settings → Environment Variables → добавь две переменные:
   - `TELEGRAM_BOT_TOKEN` — значение из шага 1
   - `TELEGRAM_CHAT_ID` — значение из шага 2
5. Нажми Save, затем зайди во вкладку Deployments и сделай Redeploy (или просто загрузи любой файл заново на GitHub — Vercel передеплоит автоматом).

Готово — теперь при отправке формы на сайте тебе будет приходить сообщение в Telegram с именем, телефоном и комментарием клиента.

## Что уже работает "из коробки"

- Кнопки в шапке и хиро — переход по разделам сайта (якоря)
- Кнопка «Написать» под каждой машиной — открывает форму заявки и подставляет в неё название машины
- Кнопка «Отправить заявку» — реально отправляет данные (после настройки Шага 4)
- Ссылка Telegram и телефон в футере — сейчас там заглушки, замени в index.html:
  - `href="https://t.me/ВАШ_ЮЗЕРНЕЙМ"` → свой юзернейм
  - `href="tel:+7XXXXXXXXXX"` → свой номер
